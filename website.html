Goals DailySavings App

A mobile application designed to help users build savings automatically through daily recurring contributions!

About the App

This application is a financial savings tool designed to help users grow their savings through automated daily contributions. Users can choose a daily savings amount within the mobile app, and the system automatically tracks and manages those savings.

Goal: Help users consistently save money through small automated daily deposits.

How Bank Connections Work

To provide a secure connection to a user's financial account, this application uses the Plaid banking integration platform.

  • Users securely connect their bank account using Plaid.
  • Plaid handles authentication directly with the bank.
  • The app never receives or stores banking login credentials.
  • Plaid returns account balance information securely.
  • The app uses this balance data to help manage automated savings features.

All financial data access is handled securely through Plaid's API infrastructure.

Application Technology

This mobile application was built using modern cloud technologies:

  • FlutterFlow – Used to design and build the mobile application interface.
  • Firebase – Provides authentication, database storage, and secure cloud services.
  • GitHub – Used for version control and hosting project files.
  • Render – Hosts the secure backend server used for API communication.

The backend server processes financial data requests and communicates securely with Plaid's API services.

Security and Data Handling

  • User authentication is managed through Firebase Authentication.
  • Bank connections are securely handled through Plaid.
  • Sensitive financial credentials are never stored on the application servers.
  • Encrypted HTTPS communication is used for all data transfers.
